# Capturas de demostración

Estas siete imágenes muestran exclusivamente datos ficticios. No proceden de un inventario del equipo ni de perfiles reales de juegos. La etiqueta DATOS FICTICIOS identifica la demostración.

El renderer se carga en un proceso aislado con sandbox, aislamiento de contexto, Node desactivado en la página y red bloqueada. Todas las respuestas IPC son fixtures; no se cargan los motores de Windows. No se aplican optimizaciones ni se leen AppData, archivos de juego o hardware.

Las capturas se revisan visualmente antes de copiarlas a esta carpeta. No deben sustituirse por screenshots del equipo del mantenedor.
