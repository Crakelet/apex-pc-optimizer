# Informar un problema de seguridad

Se aceptan informes sobre la línea actual 1.0.x. Esto no constituye una garantía de soporte indefinido.

No publiques datos privados, un exploit operativo o rutas de usuario en un issue público. El repositorio dispone de [informes privados de vulnerabilidades](https://github.com/Crakelet/apex-pc-optimizer/security/advisories/new), habilitados y comprobados el 30 de octubre de 2026. Si ese canal no está disponible para tu cuenta, abre un issue que solicite un canal privado, sin detalles sensibles.

Incluye versión, Windows, impacto, pasos mínimos y una reproducción en un entorno desechable. Si no hay canal privado disponible, abre un issue que solo solicite un canal de contacto, sin detalles sensibles.

La versión actual no carga módulos de optimización remotos, no ofrece una consola PowerShell al renderer y no ejecuta actualizaciones descargadas. Un historial dañado bloquea nuevas modificaciones: conserva ese archivo para investigar, no lo borres si aún necesitas restaurar cambios.
